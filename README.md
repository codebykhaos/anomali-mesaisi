# ANOMALİ MESAİSİ

Birinci şahıs 3D anomali bulma ve absürt komedi-korku oyunu.

> Gerçeklik Denetleme Müdürlüğü'nde mesai başladı. Lütfen gördüğünüz imkânsızlıkları vardiya bitmeden raporlayınız.

## Durum
Konsept kesinleşti. Godot 4.x tabanlı ilk oynanabilir prototip hazırlanıyor.

## Tasarım
Ayrıntılı oyun tasarım belgesi: [docs/GAME_DESIGN_DOCUMENT.md](docs/GAME_DESIGN_DOCUMENT.md)

## Teknoloji
- Godot 4.x
- GDScript
- macOS
- Compatibility renderer ile hafif 3D sahneler

## Kontroller
- WASD: hareket
- Fare: bakış
- Shift: hızlı yürüme
- E: baktığın nesneyi raporla
- F: el feneri
- Esc: fareyi serbest bırak

Godot 4.x'i kurduktan sonra Godot Project Manager içinden project.godot dosyasını içe aktar.
